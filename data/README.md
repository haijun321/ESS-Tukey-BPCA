Place no third-party face images or frozen research archives in the public
repository. The current code expects an external archive for the real-image
protocol. Set `options.archiveRoot` or the `TUKEY_ARCHIVE_ROOT` environment
variable. See [DATA_SETUP.md](../docs/DATA_SETUP.md).

The synthetic CORE and sample-layer experiments generate their own data.
The small `.mat` fixtures under the retained external-method development
directory are numerical fixtures, not a redistribution of ORL or YALE images.
